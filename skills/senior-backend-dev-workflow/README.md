# senior-backend-dev-workflow

Skill para orientar tarefas de backend da exploração e desenho até implementação, testes, segurança e revisão.

## Conteúdo

- [`SKILL.md`](SKILL.md): fluxo principal em sete fases e critérios para ajustar o rigor ao tamanho da mudança.
- [`references/api-design.md`](references/api-design.md): contratos de API, compatibilidade, paginação, idempotência e erros.
- [`references/database.md`](references/database.md): modelagem, migrações, índices, transações e concorrência.
- [`references/testing.md`](references/testing.md): estratégia de testes para serviços, bancos de dados e concorrência.
- [`references/security.md`](references/security.md): autenticação, autorização, injeção, segredos e dados sensíveis.
- [`references/observability.md`](references/observability.md): logs, métricas, rastreamento e verificações de saúde.
- [`references/code-review.md`](references/code-review.md): roteiro de revisão adversarial para mudanças de backend.
